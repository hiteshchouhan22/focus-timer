# Focus Timer

A simple Pomodoro focus timer for Android, by ShadowBox Studios.

- 25-minute focus sessions, 5-minute short breaks, 15-minute long breaks
- Start / pause / reset, with a completed-session counter
- Fully offline: no accounts, no network access, no data collection

## Build

The release Android App Bundle (AAB) is built by GitHub Actions on every push
to `main`, and uploaded as the `focus-timer-release` workflow artifact.
